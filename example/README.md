# Example app

Demo for `document_reader_sdk`. See root [README — Quick start](../README.md#quick-start).

1. AAR → `android/libdocsdk/` · iOS framework → `../ios/Frameworks/docsdk.framework`
2. Repo root: `dart run tool/bootstrap.dart` (Windows: `scripts\bootstrap.bat`)
3. iOS: `cd ios && pod install` · set **your** Xcode Team
4. `flutter run` on a physical device
