# Android AAR (plugin / your app)

Do not commit the AAR.

**Download:** [DocumentReader Android runtime (Google Drive)](https://drive.google.com/drive/folders/1nDSfvj0WtC1lZgzwFd7471ECVtk-nuYH)

Place `documentreadersdk.aar` in this folder:

```text
document_reader_sdk/android/libs/documentreadersdk.aar
```

Gradle fails the build if this file is missing (unless you are building the example, which uses `example/android/libdocsdk/` instead).
